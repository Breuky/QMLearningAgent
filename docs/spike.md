# W1 数据 Spike 清单

Spike 的目的不是写功能，而是在投入向量检索和 Agent 之前，确认**原始资料能否支撑评测目标**。

**原则**：数据不行就先修数据管道，不要用更复杂的模型掩盖解析问题。

## 准备

- 《数据结构》《操作系统》各准备 2–4 份 PPT，以及 1–2 套带答案（或可人工核对）的历年卷。
- 去掉姓名、学号、班级等个人信息；**原始文件只放在本地 `data/`，不要提交到仓库**。
- 资料入库：

```powershell
# 先创建课程，记下返回的 id
curl -X POST http://localhost:8000/api/courses -H "Content-Type: application/json" -d "{\"name\":\"数据结构\",\"term\":\"2026秋\"}"

python scripts/ingest.py --course-id 1 --file "D:\materials\ds-ch3-stack.pptx"
```

- 每次入库后查看 `GET /api/documents/{id}` 的 `status` 和 `error`。
- 需要检查切块效果时，直接查 SQLite：

```powershell
sqlite3 data/app.db "select id, document_id, page, slide_title, substr(text,1,80) from chunks where course_id=1 limit 20;"
```

（没有 `sqlite3` 命令时可用 DB Browser for SQLite 打开 `data/app.db`。）

## Spike A：PPT 解析质量

逐份资料统计：

| 检查项 | 记录方式 |
| --- | --- |
| 可提取文字的页数 / 总页数 | 如 38 / 42 |
| 纯图片页数量 | 人工翻 PPT 对照 |
| 代码页 | 抽 5 页，检查关键字、缩进、注释是否可读 |
| 表格页 | 抽 5 页，检查行列关系是否还能看懂 |
| 图示/流程图页 | 抽 5 页，记录是否只剩零散标签 |
| 演讲者备注 | 是否有额外考点 |
| 公式页 | 记录公式是否变成乱码（如 `O(nlogn)` 是否可读） |

**通过标准**

- ≥ 80% 的内容页能提取出可用文字；
- 代码页即使丢失缩进，关键字和结构仍可辨认；
- 纯图片页有明确清单，后续用 OCR / 视觉模型补齐。

**不通过怎么办**：若可用页 < 70%，先做 OCR 或接入视觉模型，不进入向量检索阶段。不要用「模型更聪明」来解释检索不到。

## Spike B：历年卷与答案核验

| 检查项 | 记录方式 |
| --- | --- |
| 总题数 | 按题型拆分 |
| 有官方答案的题数 | 选择/填空/计算/综合 |
| 提取后可读的题数 | 扫描件是否清晰 |
| 答案是否可直接采信 | 标记「已人工核对」/「仅模型生成，未核对」 |
| 可映射到 PPT 页码的题数 | 用于 Recall@5 的 `expected_sources` |

**通过标准**

- 两门课合计整理出 **≥ 30 道已核对答案的题**，其中 ≥ 15 道能标注预期来源（文件 + 页码）。
- 没有官方答案的题，必须人工核对后才能进入评测集；**模型生成的答案默认不可信**。

**不通过怎么办**：先用教材习题或自拟题补齐；历年卷只用于统计高频考点和出题，不强行进入答案评测。

## Spike C：操作系统计算题可行性

统计历年卷中的计算题类型：进程调度、页面置换、死锁检测、银行家算法、磁盘调度等。

对每类抽 2 题回答，记录：

| 类型 | 模型能否说清方法 | 数值是否正确 | 是否适合 MVP 自动作答 |
| --- | --- | --- | --- |
| 进程调度 | 是 / 否 | 是 / 否 / 不稳定 | 否，MVP 只讲方法 |
| 页面置换 | | | |
| 银行家算法 | | | |
| 磁盘调度 | | | |

**结论标准**

- MVP 只保证「方法、步骤、适用场景」的正确性，不承诺数值结果。
- 数值题在评测中只评推理过程，不评最终数字。
- W4 之后再用确定性 Python 工具计算，模型只负责解释。

## Go / No-Go 规则

- **Go**：PPT 可用页 ≥ 80%，已核对题目 ≥ 30，可标注来源 ≥ 15。进入 W2 评测集建设。
- **条件 Go**：题目足够但来源标注不足。先补页码映射，再计算 Recall@5。
- **No-Go**：PPT 可用页 < 70%。暂停检索升级，先补 OCR / 视觉解析；否则后续所有指标都不可信。

# 评测方案

评测的目标不是证明「回答看起来不错」，而是回答三个问题：

1. 该找到的资料，检索到了吗？（Recall@k）
2. 回答是否真的依据资料，引用是否对得上？（引用准确率、忠实度）
3. 不知道的时候，是否明确说不知道？（拒答正确率）

## 评测集建设

- 规模：**30–50 题**，两门课约各占一半。
- 划分：**dev / held-out ≈ 70% / 30%**。调参只看 dev，held-out 只在阶段汇报时跑一次。
- 题目来源：历年卷（答案已人工核对）、教材习题、同学真实提问（匿名化）、少量自拟题。
- 每题必须包含：课程、题型、问题、参考答案、预期来源（文件名 + 页码）、难度、dev/held-out。

### 题型分布（建议）

| 类别 | 数量 | 说明 |
| --- | --- | --- |
| 概念解释 | 8–10 | 如「什么是死锁的四个必要条件」 |
| 对比辨析 | 6–8 | 如「栈和队列的区别」 |
| 代码/复杂度 | 6–8 | 数据结构为主，允许代码片段 |
| 计算/推理 | 6–8 | OS 只评推理过程，不评数值 |
| 材料定位 | 4–6 | 明确指向某页 PPT 的内容 |
| 出题/总结 | 4–6 | 检验意图路由与生成 |
| 拒答 | 6–10 | 课程资料中不存在或超出范围 |

### 数据格式

`examples/eval_items.example.json` 是可运行样例：

```json
[
  {
    "id": "ds-001",
    "course_id": 1,
    "category": "compare",
    "question": "栈和队列的核心区别是什么？",
    "expected_sources": [
      {"document": "数据结构-第3章-栈与队列.pptx", "page": 5}
    ],
    "reference_answer": "栈是后进先出，队列是先进先出……",
    "difficulty": "easy",
    "split": "dev",
    "notes": "来源页码需与上传文件名一致"
  }
]
```

注意：

- `expected_sources[].document` 必须与上传时的**原始文件名完全一致**（包括后缀）。
- 拒答题设置 `"category": "refusal"` 且 `expected_sources` 为空；Recall 统计会自动跳过。
- `course_id` 以本地数据库为准，样例中的 id 需要替换。

### 运行检索评测

确认 API 已入库资料后：

```powershell
python scripts/run_eval.py --eval-file examples/eval_items.example.json --top-k 5
```

输出每题 Recall@5 和均值。脚本直接读 SQLite，不需要启动 API。

### Recall@k 定义

- 对每道题，取检索结果前 k 个块；
- 一个预期来源（文件 + 页码）在 top-k 中出现即算命中；
- `Recall@k = 命中来源数 / 预期来源数`；
- 多来源题取平均，最终对全部题目取平均。

当前匹配粒度为「文件名 + 页码」，不比较具体块位置。这是有意的宽松口径，便于先建立基线。

## 人工评分

### 引用准确率

抽取 20 条回答，逐条判断：回答中的关键结论是否能在所引用的页码中找到依据。

| 编号 | 问题 | 引用页码 | 结论有依据？ | 备注 |
| --- | --- | --- | --- | --- |
| 1 | | | 是 / 否 | |

`引用准确率 = 有依据的结论数 / 抽查结论总数`。

### 回答忠实度

不看引用，只看回答内容是否有资料之外的事实性扩展或错误。

| 编号 | 问题 | 回答是否只基于资料 | 错误点 | 判定 |
| --- | --- | --- | --- | --- |
| 1 | | 是 / 否 | | 忠实 / 不忠实 |

`忠实度 = 忠实回答数 / 抽查回答数`。

### 拒答正确率

准备 10 个资料中不存在、或明显超纲的问题。合格标准：明确说明「资料不足/无法确定」，且不编造具体答案。

### 有帮助率

通过 `POST /api/feedback` 收集 `rating`（如 1–5）。统计 4–5 分占比，样本量 N ≥ 5。

## 操作系统计算题评分规则

- 只评价方法选择、步骤顺序、公式与结论解释；
- 不因最终数字错误直接判错；
- 若答案给出了错误数字但仍声称「根据资料」，记为引用不忠实；
- 后续接入确定性计算工具后，再单独统计数值正确率。
